# 같은 user-agent 에 Allow 와 Disallow 를 중복 선언하지 않는다.
#
# 2026-09-03: Cloudflare 의 Managed robots.txt 를 껐다. 이제 이 파일이 그대로 서빙된다.
#       (켜면 관리형 규칙이 앞에 덧붙어 Google-Extended 가 Disallow 로 뒤집히고,
#        AI Overviews·Gemini 인용이 막힌다. Cloudflare > 도메인 > AI Crawl Control 에서 확인)

Content-Signal: search=yes, ai-input=yes, ai-train=no, use=reference
